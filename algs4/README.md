# algs4

Libreria di *Algorithms, 4th Edition* di Robert Sedgewick e Kevin Wayne, distribuita con licenza GNU GPL v3. Il [JAR incluso](algs4.jar) è la [distribuzione ufficiale di Princeton](https://algs4.cs.princeton.edu/code/algs4.jar) e contiene il codice sorgente Java e il testo della licenza nel file `COPYING`.

Dalla radice della repo, puoi estrarre i sorgenti e la licenza in una cartella temporanea.

```sh
mkdir -p build/algs4-source
unzip algs4/algs4.jar '*.java' COPYING -d build/algs4-source
```
